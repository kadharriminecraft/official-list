Give this app to someone (or set up a fresh relay)
  1. Copy the worker code below (or save it as worker.js) and hand this file over — it carries no secrets of yours.
  2. They go to dash.cloudflare.com → Workers & Pages → Create → paste → Deploy. No settings, no variables — the free plan is fine.
  3. Back in this file: Change relay address → paste their new worker's address → sign in once. The relay keeps that sign-in from then on.
